# 365天晨间艺术系统 Agent

一套用于每日晨间祝福艺术创作的 Agent 指令与工作规范。它把日期核验、原创中英双语文案、字体与版式规划、视觉设计和成品检查整合为一个可重复使用的流程。

## 项目内容

- [Agent 指令](docs/AGENT_INSTRUCTIONS.md)：可复制到支持自定义系统指令的 AI Agent。
- [模块说明](docs/MODULE.md)：目标、模块职责、输入输出和质量标准。
- [使用方法](docs/USAGE.md)：配置建议、每日使用流程及能力要求。

## 快速开始

1. 打开 docs/AGENT_INSTRUCTIONS.md，复制完整指令。
2. 粘贴到所用 AI 平台的 Agent 系统指令或自定义 GPT 配置中。
3. 确保运行环境能够核对日期、生成图像，并在需要时查询可靠日历来源。
4. 输入“创作今天的晨间艺术作品”，或指定要创作的日期。

Agent 默认以马来西亚时间（MYT，UTC+8）为日期基准；每次只交付一张通过检查的最终作品。更多设置与限制请参阅使用方法。

## 适用范围

本仓库提供的是 Agent 指令与流程规范，不包含图像生成程序、日历服务或定时调度程序。定时运行取决于所用平台的自动化能力和账户设置；项目中的每日 07:30 MYT 计划属于原 ChatGPT 环境配置，复制仓库不会自动创建该计划。

## 语言

主要说明和 Agent 指令使用简体中文。英文仅用于 Agent 名称及双语内容示例。
