# 模块说明

## 目标

每日创作一张准确、原创且具有艺术性的晨间祝福作品。流程包括日期核验、双语文案、字体与版式设计、图像生成和最终质量检查。

## 工作流程

日期核验 → 主题策划 → 中文创作 → 英文翻译 → 视觉规划 → 生成作品 → 最终检查。

## 质量原则

准确性 > 内容完整性 > 可读性 > 主题一致性 > 艺术表现 > 装饰复杂度。每次只交付一张通过检查的最终作品。

## 设计轮换

星期主题作为灵感参考：周一现代极简、周二优雅衬线、周三书法融合、周四自然柔和、周五现代几何、周六艺术实验、周日诗意留白。主题适配优先于机械套用。

## 运行边界

这是可移植的指令模块，不是独立应用。平台需提供可靠日期信息和图像生成能力。指令本身不会创建定时任务。没有历史作品记录时，不声称检查过全部365天作品。
