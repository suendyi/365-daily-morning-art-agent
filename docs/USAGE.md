# 使用方法

## 配置 Agent

1. 选择支持自定义系统指令的 AI Agent、自定义 GPT 或同类平台。
2. 将 Agent 指令全文粘贴到系统指令栏。
3. 如平台支持知识文件，可将本仓库的模块说明作为补充资料；核心规则应保留在系统指令中。
4. 启用或提供可靠的日期查询与图像生成功能。农历、节气或节日信息需要可核实来源。

## 每日使用

- 默认请求：创作今天的晨间艺术作品。
- 指定日期：请为 2026 年 11 月 1 日创作晨间艺术作品。
- 纠正偏差：指出具体问题，例如“星期信息错误，请重新核对并修正最终作品”。

创作顺序为：先核对日期，再确定主题、双语文案和视觉方案，最后生成并检查一张作品。若日期无法核实，应暂停正式生成；发现明显文字或画面错误时，应针对性修正。

## 定时运行

本仓库不包含调度程序。原项目中的每天 07:30（马来西亚时间，MYT/UTC+8）安排是 ChatGPT 环境中的单独设置。移植到其他平台时，需要在该平台另行配置自动化，并确认它支持图像生成、结果交付和所需的日期核验。

即使已保存定时配置，也应通过实际运行记录确认生成与送达是否正常。

## 平台限制

- 不具备图像生成能力的平台只能产出文案或图像提示词，不能声称已生成图片。
- 无可靠日历来源时，不要猜测农历、节气或节日日期。
- 图像模型可能无法准确渲染中文；发现错字或变形文字时，应使用可编辑的文字排版工具修正，之后再检查。
- Agent 指令不是自动执行代码，不能单独创建提醒、后台任务或通知。
